# NOVA

Простой ассистент с голосовым управлением на русском языке.

## Возможности
* Распознавание речи через `speech_recognition` без ключевых фраз.
* Озвучивание текста с помощью `pyttsx3`.
* Управление системой: запуск и завершение программ, выключение, перезагрузка и
  блокировка ПК, регулировка громкости, список процессов, выполнение команд чере
  PowerShell и CMD.
* Работа с файлами: поиск, копирование, удаление и переименование.
* Telegram-бот для удалённого управления, отправка логов и скриншотов, удалённое
  выключение ассистента.
* Создание скриншотов экрана по команде.
* Графический интерфейс на Tkinter с очисткой логов и перезапуском.
* Плагины: погода, поиск в браузере, проверка обновлений.
* Планировщик задач на базе `schedule`.
* Самообучение через GPT и база данных SQLite с запоминанием команд.

## Запуск
```
python main.py             # запуск GUI
python main.py --nogui     # без графического интерфейса
python main.py --bot       # запуск Telegram-бота
```

При первом запуске создаётся база данных `nova.db`, где сохраняются введённые команды и ответы ассистента. Модуль `learning.py` может отправлять части кода в GPT для получения рекомендаций по улучшению.
